# Pathly

Landing page for **Pathly** — a two-sided platform that connects local businesses with nearby creators. Campaigns are posted, creators apply, and matched conversations move to WhatsApp.

## Messaging

> Post the work. Get matched.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Paths

| Path | Audience |
|------|----------|
| `/` | Landing |
| `/signup/business` | Business signup → first campaign |
| `/signup/creator` | Creator signup → discovery |
| `/#waitlist` | Waitlist (email + city + role) |
